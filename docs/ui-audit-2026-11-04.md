# Harbor UI audit and refinement — 4 November 2026

## Scope and direction

Operate mode: preserve Harbor’s calm control-plane identity, routes, real data, Bricolage Grotesque text face, Inconsolata for paths/code, and Lucide icons. Three subagents independently covered shell/navigation, resources/shared tables, and operations/settings. The parent reviewed integration, primitives, and rendered output.

Design Taste direction: **Achromatic ledger**, seed **618988119**, palette and type preserved. No redraws. Its neutral chrome and restrained status color fit the incumbent. Existing labeled navigation remains because Harbor has many unfamiliar destinations; an icon-only replacement would undermine discoverability. Harbor’s distinctive content is its agent detection, resource locations, validation issues, and scoped project switcher. No invented data, imagery, claims, fonts, or dependencies were introduced.

## Findings addressed

| Priority | Finding and impact | Refinement |
| --- | --- | --- |
| P1 | Resource sheets had a 640px minimum width at a 640px viewport | Bound detail sheets to the viewport; wrap metadata and footer actions |
| P1 | Long paths and unconstrained flex children could push content beyond the viewport | Allow shrinking; wrap paths and stack detail fields |
| P1 | Table identity columns could collapse to one character per line | Give the mobile identity column a 160px minimum, keep it sticky, contain horizontal scroll |
| P1 | Several workflow form labels were not associated with their controls | Add stable input/trigger IDs and label associations |
| P1 | Clickable rows lacked consistent keyboard affordances | Visible row focus; actual links on operations rows; ignore keyboard events from nested controls |
| P1 | Terminal close controls were nested inside tab buttons | Separate selected-session close button from the tab list |
| P1 | Dashboard automation printed empty states during loading/API failures | Distinguish loading, error/retry, and successful empty states |
| P2 | Full sidebar consumed one third of tablet width | Fold navigation below 1024px; keep desktop labeled navigation |
| P2 | Mobile drawer stayed open after selecting a destination | Close drawer on ordinary route activation; preserve modified-click behavior |
| P2 | Nested agent routes lost their active navigation indication | Prefix-aware selection and `aria-current` |
| P2 | Search affordance lost its visible mobile label | Visible search description and accessible command-palette name |
| P2 | Dialogs could exceed short viewports | Dynamic viewport max heights and contained vertical scrolling |
| P2 | Workflow input/retry grids were too dense at narrow widths | Delay wide grids; stack retry fields; wrap headers/actions |
| P2 | Touch controls and mobile text fields were undersized | Coarse-pointer 44px control targets and 16px mobile input text |
| P2 | Settings execution fields were far from their save action | Add a save action beside that section |
| P2 | Empty/error states introduced nested frames or overflowed long messages | Remove redundant frame; wrap error text; truthful filtered empty state |
| P3 | Titles, numeric columns, graph metadata, and theme surfaces drifted | 20/24px titles, tabular/right-aligned numeric fields, readable graph text, neutral dark surfaces |
| P3 | Card ring rendered as a resting shadow | Use the existing border token instead |
| P3 | Browser defaults and reduced-motion behavior were inconsistent | Skip link, document titles, focus, selection, scrollbars, color scheme, reduced-motion log follow |

## Remaining limits

- Full keyboard-only traversal, screen-reader testing, every dark-mode route, 200% zoom, and exhaustive contrast measurement were not performed.
- Job detail/live logs, populated schedules/workflow runs, and active terminal sessions were source-reviewed but not exercised with generated data. Mutation/save/install/delete flows were not invoked.
- Tables intentionally scroll inside their own frame on small devices. The sticky identity column preserves context; a future row-list design would be a larger interaction change.
- The resource editor’s existing bundle size merits a separate performance task. Existing ResourceEditor warnings remain.
- The supplied health-endpoint failure did not reproduce against the isolated API, which returned actual health counts. This does not establish its behavior for other installations/databases.

Local evidence and repeatable browser scripts live in `.taste-skill/` (generated, ignored). No source commit was made.
