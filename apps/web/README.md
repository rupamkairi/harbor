# Harbor Web

Svelte 5 interface shared by the browser and Electrobun desktop app.

Run `bun run dev` from the repository root for the API and Vite together.
Use `bun run dev:web` for the UI only, `bun run typecheck` for checks, and
`bun run package:desktop` to build the native app.

See the [project README](../../README.md) for setup and packaging.
